# WorkDesk

WorkDesk — сборка RustDesk 1.5.1 (https://github.com/rustdesk/rustdesk) с собственным брендом и встроенными настройками сервера.

Лицензия: GNU AGPL-3.0 (см. LICENCE). Исходный код этой сборки: https://github.com/Ismagulovne/workdesk-client

Изменения внесены скриптом prepare_fork.py проекта WorkDesk: имя программы, иконки, сведения о файле, встроенные адреса сервера, сценарий сборки.
